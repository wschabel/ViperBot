## ⚡ Zero-Tab Control: Quick Command Guide

You never need to tab out of your game or pull up heavy browser dashboards mid-stream. Control 100% of ViperBot directly through live chat inputs:

| Action | Chat Command Syntax | Description |
| :--- | :--- | :--- |
| **Add Command** | `!addcom commandname Your response here` | Creates a new text command instantly. |
| **Edit Command** | `!editcom commandname Your updated text` | Modifies an existing command live. |
| **Delete Command**| `!delcom commandname` | Permanently removes a custom command. |
| **Add Timer** | `!addmsg Your automated reminder` | Sets up a recurring message (socials, schedules). |
| **Edit Timer** | `!editmsg messagenumber New text` | Edits an automated reminder by its ID number. |
| **Delete Timer** | `!delmsg messagenumber` | Removes an automated message from rotation. |
| **Set Interval** | `!msgint number` | Configures the number of regular chat lines required between automated timer triggers. |
